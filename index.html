Liner
Desktop Video-Production Engine · ML + FFmpeg

A macOS production app I built to make 10+ lyric videos a week possible — a volume that's simply not achievable by hand. It runs a full ML pipeline (Mel-RoFormer vocal isolation → Whisper large-v3 transcription → forced alignment) to sync official lyrics to exact word-level timestamps, then renders 4K video server-side with FFmpeg drawtext and hardware encoding — cutting a 1-hour render from 20+ minutes to 3–5. ~15K lines of code across a Node/Express backend, a vanilla-JS SPA, and Python ML scripts.

03 / 05
Weave
AI-Agent Video Editor · Local-First · Python + LLM

A local-first editor that turns a raw 2-hour Zoom recording into a finished, branded video — automatically. An agent transcribes (whisper.cpp on Metal), detects cuts with refined heuristics (dead air, filler words, false starts, Zoom chatter), and uses Claude to find the strongest narrative hook and reorder for it — every decision auditable and reversible. Renders 4K with concurrent FFmpeg + hardware encoding (a 2-hour video in ~20 min) and exports either an MP4 or a Premiere bridge. In production: 3+ videos/week for a coaching brand, cutting ~6 hours of manual editing per video.
